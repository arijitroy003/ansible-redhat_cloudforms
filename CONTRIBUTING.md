# Contributing to ansible-redhat_cloudforms

Thank you for your interest in contributing to this project.

## How to Contribute

1. Fork the repository and create a feature branch from `master`.
2. Make your changes, ensuring they follow the existing code style.
3. Test your changes locally.
4. Submit a pull request with a clear description of the change.

## Reporting Issues

Please use [GitHub Issues](https://github.com/RedHatOfficial/ansible-redhat_cloudforms/issues) to report bugs or request features. Include:

- A clear description of the problem or suggestion
- Steps to reproduce (for bugs)
- Expected vs. actual behavior

## Code Style

- Follow [Ansible best practices](https://docs.ansible.com/ansible/latest/tips_tricks/ansible_tips_tricks.html) for playbooks and tasks.
- Use meaningful variable names and add comments where necessary.
- Keep playbooks and tasks idempotent.
